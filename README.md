# MT Rankings

MT Rankings ist ein Prototyp für eine Muay-Thai-Ranking-Website. 
Die Anwendung soll Rankings verschiedener Organisationen wie RWS, ONE Championship und WBC Muay Thai übersichtlich darstellen.

## Hauptworkflow

User können Rankings ansehen, einen Kämpfer auswählen, die Detailseite öffnen und Kämpfer als Favorit speichern.
